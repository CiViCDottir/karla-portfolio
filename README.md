background, skills, projects, and contact information.

## About

I'm a final-year BSc Information Technology student at North-West
University, with a focus on databases, information security, and systems
analysis. This site pulls together my CV into an interactive format,
including project write-ups with real results from coursework.

## Built with

- HTML5
- CSS3 (custom properties, Flexbox, CSS Grid, media queries)
- Vanilla JavaScript (scroll animations, light/dark mode toggle)
- No frameworks or libraries — built from scratch to properly learn the fundamentals

## Features

- Responsive layout (desktop, tablet, and mobile)
- Light / dark mode toggle, saved between visits
- Scroll-triggered animations
- Sections: About, Skills, Projects, Contact

## Running it locally

1. Clone this repository: git clone https://github.com/CiViCDottir/karla-portfolio.git
2. Open the folder in VS Code
3. Install the **Live Server** extension if you don't have it
4. Right-click `index.html` → **Open with Live Server**

No build steps, no dependencies to install — it's plain HTML/CSS/JS.
