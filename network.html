The problem

Our brief was to design a business network from real-world requirements: segmenting the network, isolating departments from each other, providing wireless connectivity and giving the whole organisation internet access.

My role

As project leader, I built most of the network in Cisco Packet Tracer and led our presentation to the lecturer. I delegated the budget to the rest of the team.

Approach

We built the network in Cisco Packet Tracer as a hierarchical design, with core switches linking access switches that connect separate departmental LAN segments. It includes routers, servers, wireless access points for laptops, shared printers and workstations across the departments. Alongside the build we prepared network documentation and budget considerations using realistic hardware costs.

Tools

Cisco Packet Tracer Network Design LAN Segmentation Wired & Wireless Networking Technical Documentation

Decisions and challenges

I decided to build most of the network in Cisco Packet Tracer seeing as there isn't a way to merge different Packet Tracer simulations. i had the rest of the team map the basic network for their given areas and I built the connections between them.

Result

A documented and costed network design that earned 84% as a final project.
